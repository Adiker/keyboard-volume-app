---
title: Keyboard Volume App
description: Control individual application volume on Linux with keyboard and mouse hotkeys.
---

Keyboard Volume App controls the volume of a selected application using global keyboard or mouse hotkeys, with a configurable on-screen display.

Use the sidebar to open the installation instructions, user guide, configuration reference, and remote-control guide.

For source code, contributions, and maintainer documentation, visit the [GitHub repository](https://github.com/Adiker/keyboard-volume-app).
